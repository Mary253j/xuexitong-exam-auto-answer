# 学习通考试自动答题

Android 应用名称为 **题页助手**。当前版本 **1.0.19**：在助手内打开官方网页，读取题目并显示模型参考答案，由使用者自行选择、填写和提交。

[下载 Android 1.0.19 安装包](downloads/quizhelper-1.0.19.apk) · [1.0.19 发布页](https://github.com/Mary253j/xuexitong-exam-auto-answer/releases/tag/v1.0.19) · [网页使用说明](WEB_TESTING.md) · [发布前隐私检查](PRIVACY_REVIEW.md)

支持 Android 8.0 及以上，不依赖 AutoX，没有第三方运行依赖或原生架构库。已有相同包名、相同签名的版本可以直接覆盖安装，保留本机配置。模型功能需要使用者在手机中填写自己的硅基流动 API Key 和完整模型 ID，仓库与安装包不提供共享 Key。

## 当前功能

- **紧凑网页界面**：顶部保留三行常用操作；缩放、显示模式、诊断等收进“更多工具”。默认答案区与网页按剩余高度约 1:3 分配空间。
- **单题与多题**：单题可指定本页题号，多题依次处理本页可解析题目，最多读取 500 道。两道题开始处理至少间隔 5 秒，模型请求较慢时等待完成。
- **直接显示答案**：选择题和判断题紧凑排列，例如 `1.B2.AC3.对`；多选字母按选项顺序显示。判断题依据实际选项正文转换为“对/错”，无法明确转换时保留字母。
- **问答题**：支持明确标注的简答题、问答题、论述题。保留参考正文与段落，“复制问答”可以按题号复制，由使用者自行粘贴。
- **完整性检查**：核对题型、题干、选项与页面顺序；读取截断会停止并说明原因。题目预览或诊断明细的省略与实际读取截断分开处理。

网页模式不自动点击选项，不填写、保存或提交答案。它只运行随 APK 提供的题目读取脚本，并在 Android 原生代码中调用模型、显示参考答案。

## 安装和使用

1. 安装 `quizhelper-1.0.19.apk`，打开“题页助手”。
2. 在主页填写 API Key 和完整模型 ID，点击“保存 Key 和模型配置”。可以先用“测试 API 连接”发送一条简短测试题，检查连接和答案格式。
3. 点击 **打开网页参考答案**，在超星官方网页自行登录并进入课程、作业或题页。网页模式无需无障碍授权，进入时会停止原 APP 模式。
4. 选择 **单题** 或 **多题**。单题的“题号”按当前网页的题目出现顺序计数；多题模式保留但禁用该输入框。
5. 点击 **检测文字**，核对题干和选项。该按钮不会请求模型或操作答案。题目在独立框架中时，可在“更多工具”中选择“打开题目框架”。
6. 点击 **获取答案**，首次读取在 5 秒后开始。保持题页前台，参考答案显示在网页上方；自行核对并选择或填写。
7. 点击 **停止获取** 可以结束本轮。页面跳转、离开前台、切换模式或题号也会停止；已生成答案保留在当前进程中。新一轮获取会重新建立本轮答案列表。
8. 完成后由使用者自行保存或提交。“更多工具”保留官方首页、缩放、手机/电脑版切换、清除网页登录和复制问题反馈等功能。

API Key 使用 Android Keystore 管理的 AES-GCM 密钥加密保存在本机应用私有数据中。切换应用、停止或进程重启后无需重新填写；卸载或清除应用数据会删除配置。“删除已保存的 Key”用于主动清除凭据。“清除网页登录”只清理助手内的 Cookie、站点存储和缓存，不删除 API Key。

## 保留的原 APP 模式

主页仍保留独立的无障碍 APP 模式：读取 `com.chaoxing.mobile` 提供的题目文字，条件满足时可自动选择选项。该模式需要使用者手动启用无障碍服务；它与上述网页参考答案模式不同。

APP 模式保留单题、多题、只检测文字，以及停止并关闭无障碍服务等控制。没有原生点击操作时，会在重新核对的选项节点位置轻点；不会自动翻题、滚动、保存或提交。部分学习通单题页面不向无障碍提供完整选项正文，这类页面仍可能无法处理。

多选题的选中状态无法读取时，默认只显示答案。可选的“按空白题选择一次”需要先手动清空已有勾选；程序保存题目哈希和点击记录，避免重复点击取消选择。新一轮重测前需核对页面并按需重置记录。APP 问答题仅提供参考正文和复制功能，不自动填写。

## 数据和权限

| 项目 | 实际行为 |
| --- | --- |
| 普通应用权限 | 仅申请 `android.permission.INTERNET` |
| 无障碍 | 独立 APP 模式使用，服务由系统绑定；网页模式无需启用 |
| 屏幕与窗口 | 无截图、录屏、屏幕 OCR、系统分屏或跨应用悬浮窗功能；`canTakeScreenshot=false` |
| 模型接口 | 固定为硅基流动 HTTPS 对话接口，不跟随重定向；发送解析出的题型、题干和选项，Key 只用于原生请求头 |
| 网页 | 超星官方 HTTPS 页面及本机 WebView 登录状态；没有 JavaScript 原生接口，Key 不注入网页或 URL |
| 本地保存 | 加密 Key、模型与模式配置、原 APP 模式的多选点击记录；WebView 保存 Cookie 与站点存储，系统备份关闭 |
| 检测与答案 | 有界检测报告、参考答案和加载事件保留在进程内存中；主动复制时才写入剪贴板 |

自身配置页和网页界面启用 `FLAG_SECURE`。没有广告、统计 SDK、通用脚本执行器、自动更新或开机启动功能。反馈不主动包含 Key；复制问题反馈前仍应检查题目文字中是否含姓名、学号等个人信息。

上方控制区、答案区与下方网页属于同一个 Android Activity 的普通布局。网页仍可能感知焦点、尺寸或页面事件；本项目没有规避监测的功能，也无法承诺平台如何判定使用行为。

## 使用限制

- 需要可读取的文字和明确题型。图片、画布、图片公式、缺失材料、字体编码不明、选项冲突或真正截断的内容可能被跳过或停止处理。
- 当前最多读取 500 道题，还存在候选节点、文字总量和单字段长度限制。超限时会明确提示，不根据不完整页面继续获取。
- 参考答案来自模型推理，当前没有接入联网搜索或官方题库，可能答错。模型回复还需通过题号、题型和选项字段校验。
- 网页模式仅处理助手内打开的网页，不能读取其他浏览器内部页面。离开前台后不会继续本轮获取。
- 无障碍与联网限制由代码落实，不等于 Android 提供了严格的单应用、单域名沙盒。加密密钥是否由硬件保护取决于设备。

## 构建与验证

源码位于 `app/src/main`。使用 Linux、JDK 17+、Python 3、Android SDK Platform 35 和 Build Tools 35.0.1 构建：

```sh
python3 build.py \
  --platform-jar /path/to/android-sdk/platforms/android-35/android.jar \
  --build-tools /path/to/android-sdk/build-tools/35.0.1
```

`build.py` 会在本地 `.private/` 生成自己的签名证书和密码文件，目录已加入忽略规则，请勿提交或分享。公开源码不包含发布 APK 的签名私钥；自行构建的签名通常不同，不能直接覆盖本仓库提供的安装包。

验证范围与操作说明见 [WEB_TESTING.md](WEB_TESTING.md)，凭据检查见 [PRIVACY_REVIEW.md](PRIVACY_REVIEW.md)。本地测试覆盖网页读取、答案队列与展示、权限和网页只读行为；不能替代真实手机布局、Android Keystore、实际模型请求或网站行为验证。1.0.18 的大题量读取修复已得到使用者反馈确认，1.0.19 的紧凑布局仍待真机确认。
